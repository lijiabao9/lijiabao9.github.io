修改管理员密码

登录后台

访问 https://openlist.yourdomain.com，账号 admin，密码为上一步设置的新密码。

进入 管理 → 设置 → 其他，配置下载器地址（使用容器名称互通）：

  • Aria2 配置:

    • 地址: 改为 http://oplist-aria2-pro:6800/jsonrpc
    • 密钥: 输入在 .env 中配置的 OPLISTDX_ARIA2TOKEN 对应的值。
    • 点击保存，系统会自动检测并提示连接成功。

  • qBittorrent 配置:

    • 地址: 改为 http://admin:adminadmin@oplist-qbittorrent:8080/
    • 认证注意: 新版 Linux server 镜像出于安全考虑去掉了默认密码 adminadmin。每次启动时会随机生成密码，请运行命令 docker logs oplist-qbittorrent 查看日志输出的密码。
    • 修改密码： 访问 Web 管理界面 http://ip:8080 修改用户名和密码，否则每次容器重启都会生成新密码。

  • Transmission 配置:

    • 地址: 改为 http://oplist-transmission:9091/
    • 认证账户与密码对应 .env 中填写的参数（若未开启认证则保持默认）。
